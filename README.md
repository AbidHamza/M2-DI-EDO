# M2-DI-EDO - Projets DevOps et DevSecOps

## Description

Ce depot contient deux projets pedagogiques complets pour apprendre l'observabilite DevOps et le CI/CD DevSecOps. Chaque projet est concu pour garantir votre succes avec des guides detailles et des instructions pas a pas.

## Projets disponibles

### Projet 1 : Observabilite DevOps

Apprenez a mettre en place une stack ELK complete pour monitorer des donnees, depuis la preparation jusqu'au deploiement en production.

**Duree estimee** : 5-6 heures (debutant) ou 3-4 heures (intermediaire)

[Commencer le Projet 1](PROJET-1-OBSERVABILITE/README.md)

### Projet 2 : CI/CD DevSecOps

Apprenez a creer un pipeline CI/CD securise avec GitLab CI/CD et des outils gratuits.

**Duree estimee** : 3-4 heures

[Commencer le Projet 2](PROJET-2-CICD-DEVSECOPS/README.md)

## Prérequis

- Compte GitLab (gratuit) - https://gitlab.com
- Docker installe
- Python 3.8 ou superieur
- Editeur de code (VS Code recommande)

## Comment utiliser ce depot

1. Clonez ce depot sur GitLab
2. Choisissez un projet selon votre niveau
3. Suivez les etapes dans l'ordre (01, 02, 03...)
4. Validez chaque etape avant de passer a la suivante

## Structure pedagogique

Chaque projet suit une structure progressive avec des etapes numerotees :

- Etape 01 : Preparation
- Etape 02 : Configuration initiale
- Etape 03 : Implementation
- Etape 04 : Tests et validation
- Etape 05 : Deploiement

Chaque etape contient :
- Un guide complet avec instructions pas a pas
- Des exemples concrets
- Des solutions aux problemes courants
- Des verifications pour valider votre travail

## Outils utilises (tous gratuits)

- GitLab (plateforme principale)
- GitLab CI/CD (pipeline CI/CD gratuit)
- Docker et Docker Compose
- Elasticsearch, Logstash, Kibana (ELK Stack)
- Railway.app, Render.com, Fly.io (deploiement gratuit)
- Python, Bash

## Besoin d'aide ?

Consultez les guides de depannage dans chaque projet ou ouvrez une issue sur GitLab.

Bon apprentissage !

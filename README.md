# M2-DI-EDO - Projets DevOps et DevSecOps

## Description

Ce depot contient des projets pedagogiques complets pour apprendre l'observabilite DevOps, le CI/CD et le DevSecOps. Chaque projet est concu pour garantir votre succes avec des guides detailles, des verifications automatiques et des solutions a tous les problemes.

Plateforme utilisee : GitLab (tous les outils sont gratuits)

## Navigation rapide

- [Guide de demarrage](GUIDE-DEMARRAGE.md) - Commencez ici
- [Resolution de problemes](TROUBLESHOOTING.md) - Si vous etes bloque
- [Checklist complete](CHECKLIST-PROJET.md) - Suivez votre progression

## Projets disponibles

### Projet 1 : Observabilite DevOps

Apprenez a mettre en place une stack ELK complete pour monitorer des donnees, depuis la preparation jusqu'au deploiement en production.

Duree estimee : 5-6 heures (debutant) ou 3-4 heures (intermediaire)

Etapes :
1. Preparation de l'environnement
2. Generation de donnees de test
3. Deploiement de la stack ELK
4. Visualisation avec Kibana
5. CI/CD avec GitLab CI/CD
6. Containerisation avec Docker
7. Deploiement gratuit en production

[Commencer le Projet 1](PROJET-1-OBSERVABILITE/README.md)

### Projet 2 : CI/CD DevSecOps

Apprenez a creer un pipeline CI/CD securise avec GitLab CI/CD et des outils gratuits.

[Commencer le Projet 2](PROJET-2-CICD-DEVSECOPS/README.md)

### Lab0 : Equations differentielles

Introduction aux equations differentielles ordinaires avec Python.

[Commencer le Lab0](LAB0-EDO/README.md)

## Prérequis

- Compte GitLab (gratuit) - https://gitlab.com
- Docker installe (voir GUIDE-DEMARRAGE.md)
- Python 3.8 ou superieur
- Editeur de code (VS Code recommande)

## Comment utiliser ce depot

1. Lisez le [Guide de demarrage](GUIDE-DEMARRAGE.md)
2. Creez un compte GitLab si vous n'en avez pas
3. Clonez ce depot sur GitLab
4. Choisissez un projet selon votre niveau
5. Suivez les etapes dans l'ordre (01, 02, 03...)
6. Validez chaque etape avant de passer a la suivante
7. Consultez les guides de depannage si necessaire

## Garantie de succes

Chaque etape contient :
- Des instructions pas a pas detailees
- Des scripts de verification automatique
- Des exemples de sorties attendues
- Des solutions a tous les problemes courants
- Des alternatives si une methode ne fonctionne pas

Si vous suivez les guides dans l'ordre et validez chaque etape, votre succes est garanti a 100%.

## Outils utilises (tous gratuits)

- GitLab (plateforme principale)
- GitLab CI/CD (pipeline CI/CD gratuit)
- GitLab Container Registry (registry Docker gratuit)
- GitLab Pages (hebergement gratuit)
- Docker et Docker Compose
- Elasticsearch, Logstash, Kibana (ELK Stack)
- Railway.app, Render.com, Fly.io (deploiement gratuit)
- Python, Bash

## Besoin d'aide ?

1. Consultez le guide TROUBLESHOOTING.md
2. Consultez PROBLEMES-SOLUTIONS.md dans chaque etape
3. Executez les scripts de diagnostic (diagnose.sh)
4. Verifiez les exemples dans SORTIE-ATTENDUE.md

## Structure pedagogique

Chaque projet suit cette structure :

- README.md : Vue d'ensemble et objectifs
- INSTRUCTIONS-PAS-A-PAS.md : Instructions numerotees detailees
- VERIFICATION.md : Comment verifier que tout fonctionne
- PROBLEMES-SOLUTIONS.md : Solutions a tous les problemes
- SORTIE-ATTENDUE.md : Exemples de ce que vous devriez voir
- Scripts : Scripts automatises pour installation et verification

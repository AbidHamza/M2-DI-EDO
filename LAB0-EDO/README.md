# Lab0 : Equations differentielles ordinaires

## Description

Ce laboratoire introduit les concepts de base des equations differentielles ordinaires (EDO) et leur resolution numerique avec Python.

## Objectifs pedagogiques

A la fin de ce laboratoire, vous serez capable de :
- Comprendre les concepts de base des equations differentielles ordinaires
- Resoudre des EDO numeriquement avec Python
- Visualiser les solutions d'EDO
- Utiliser les bibliotheques scientifiques Python (numpy, scipy, matplotlib)

## Prérequis

- Python 3.8+ installe
- Bibliotheques Python : numpy, matplotlib, scipy
- Editeur de code

## Installation

1. Creez un environnement virtuel Python :
```bash
python -m venv venv
```

2. Activez l'environnement virtuel :
- Windows :
```bash
.\venv\Scripts\activate
```
- Linux/Mac :
```bash
source venv/bin/activate
```

3. Installez les dependances :
```bash
pip install -r requirements.txt
```

## Structure du projet

- lab0.py : Contient les implementations des solutions
- requirements.txt : Liste des dependances Python
- README.md : Documentation du projet

## Execution

Pour executer le code :
```bash
python lab0.py
```

## Contenu

Ce laboratoire couvre :
- Introduction aux equations differentielles ordinaires
- Resolution numerique avec scipy.integrate.solve_ivp
- Visualisation des solutions avec matplotlib
- Exemples pratiques
